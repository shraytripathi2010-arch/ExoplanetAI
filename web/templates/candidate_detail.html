How sure is the model? (conformal prediction)

The probability above is a single number. This turns it into the set of statuses that are still plausible at a given confidence level — which lets the model say “I don't know” instead of quietly returning a middling number. This is the model assessing itself; it is not evidence about the star. For external human assessment see the TFOP panel below.

{% for s in conformal_view.sets %} {% endfor %}
Confidence levelStill plausibleWhat that means
{{ s.confidence_pct }}% {{ s.set_label }} {{ s.plain_language }}

Read the rows together: a status that survives at 99% is one the model cannot rule out even when being very cautious. A star that reads “Planet” at 90% but “Planet or not a planet” at 99% is a moderately confident call, not a certain one. Sets only ever grow as the confidence level rises — being more careful means ruling out less.

These answer a different question from the probability above. The probability says which status is more likely. These sets say which statuses cannot be ruled out. The two can point different ways, and that is not a contradiction: a candidate scoring 0.62 can still have “not a planet” in its set, because confirmed false positives do sometimes score that high, and ruling one out at 90% confidence takes more evidence than merely leaning against it.

What the guarantee is, and where it stops applying

Calibrated on {{ conformal_view.n_calibration }} labelled TESS stars ({{ conformal_view.n_calibration_pos }} confirmed planets, {{ conformal_view.n_calibration_neg }} false positives) that the model was never trained on, using {{ conformal_view.method }}. On stars drawn from that same population, the true status falls inside the set at least as often as the stated confidence level — measured, not assumed, and verified separately for planets and for false positives.

Legitimate next steps toward confirmation

Be realistic: nothing this site does can move a candidate to "confirmed." Real confirmation requires spectroscopic follow-up and independent observation by qualified researchers with telescope/spectrograph access. What this site CAN do is point you to the real, existing community mechanism for that:

  • View this target on ExoFOP-TESS -- the real community follow-up portal, viewable by anyone with no login.
  • Request a free ExoFOP account -- required to submit a candidate as a community TOI or comment on a target; genuine follow-up observation requests go through the separate TFOP (TESS Follow-up Observing Program) membership process, not a self-serve button.
