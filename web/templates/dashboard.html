Run a full Update

This can take a long time (past runs of ~1,000 stars took multiple hours) -- it runs in the background, so you can leave this page and come back. Existing candidates stay fully browsable while it runs.

Automatic scheduling

Runs the same Update automatically on an interval, no button click needed. This only fires while this app (python3 app.py) is running -- closing the terminal or letting the Mac sleep pauses it, same as any background job here. For a schedule that survives that, see web/README_SCHEDULING.md for an optional macOS launchd setup (a real change to your machine's startup behavior, so that's documented rather than done automatically).
